# Portafolio de Power BI | Ignacio Cubero

Colección de proyectos de práctica enfocados en la visualización de datos comerciales y académicos con Power BI.

## Proyectos

| Proyecto | Enfoque |
|---|---|
| [Análisis de ventas 2018–2020](powerbi-analisis-ventas/README.md) | Indicadores de ventas, comparación interanual y ranking de clientes. |
| [Análisis de calificaciones 2018–2022](powerbi-calificaciones/README.md) | Promedios académicos y distribución de estudiantes. |
| [Análisis de pedidos y ventas internacionales](powerbi-pedidos/README.md) | Comparación de pedidos, montos por país y tipos de envío. |

Cada proyecto incluye una descripción, imágenes del informe y su archivo editable `.pbix`. Las imágenes permiten revisar el trabajo directamente en GitHub; descarga el archivo PBIX y ábrelo con Power BI Desktop para explorar el informe.

Los proyectos son prácticas académicas. Los archivos conservan los datos incorporados en los informes; los archivos externos de origen no se incluyen. Actualizar los datos puede requerir ajustar las rutas de origen en Power Query.
