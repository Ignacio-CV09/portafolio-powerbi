# Análisis de ventas 2018–2020 | Power BI

**Autor: Ignacio Cubero**

Proyecto de práctica en Power BI para presentar el desempeño de ventas, comparar los indicadores con el año anterior e identificar los clientes con mayor volumen de ventas.

## Vista del dashboard

![Dashboard de análisis de ventas 2018–2020](dashboard-ventas.png)

## Objetivo

Reunir los principales indicadores comerciales en una vista que facilite responder:

- ¿Cuál es el monto de ventas en el contexto seleccionado?
- ¿Cómo se compara con el año anterior?
- ¿Qué clientes concentran las mayores ventas?

## Contenido del informe

- Tarjetas de ventas totales, ventas del año anterior, variación absoluta y variación porcentual.
- Gráfico de barras de ventas por cliente, ordenado de mayor a menor.
- Controles visuales de años, países y clientes, y un selector de vendedor.
- Elementos gráficos para identificar países y clientes.

## Resultados visibles

La captura exportada presenta los siguientes valores:

| Indicador | Valor mostrado |
|---|---:|
| Ventas totales | $1.35 millones |
| Ventas del año anterior | $982.84 mil |
| Variación frente al año anterior | $366.37 mil |
| Variación porcentual | 37.28% |

En el ranking visible, Google registra el mayor volumen de ventas, seguido por Amazon.com y Sherwin Williams. La comparación presentada muestra un incremento del 37.28% frente al año anterior.

Los valores corresponden al contexto de filtros de la captura; no deben interpretarse como el total de todo el período 2018–2020. El símbolo monetario se conserva tal como aparece en el informe, sin atribuir una moneda específica.
